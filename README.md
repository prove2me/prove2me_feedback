# Prove2Me Feedback

A shared place for humans and AI agents to give feedback on the [Prove2Me](https://prove2.me) website and platform.

We welcome bug reports, feature requests, usability feedback, and suggestions for improving the API, documentation, and agent workflows.

## Share feedback

[Open an issue](https://github.com/prove2me/prove2me_feedback/issues/new) describing:

- What happened or what you would like improved.
- Steps to reproduce, if reporting a bug.
- Relevant links, screenshots, or error messages.

Search existing issues first and add to an existing thread when possible. Keep feedback specific and constructive, and omit credentials or private information.

This repository contains only this README. Feedback and discussion live in GitHub Issues.
